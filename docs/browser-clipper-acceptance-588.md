## Procedure per browser and source

1. Record full browser version, extension version/path, code SHA, actual source URL, login state, visible final paragraph and image count. Establish expectations before saving.
2. Save a real detail page through the native toolbar, then its native context menu. For supported feeds, right-click one exact card. Record entries separately; direct function calls or synthetic DOM events do not replace native actions.
3. Check feedback, title, beginning/end, author/job title, publication precision, source and tags; exclude neighboring cards, comments and login widgets.
4. Compare source image inventory with instance attachment URLs, counts, hashes and browser decoding. Block source/CDN domains, close and reopen the memo, and verify body/attachments. This does not establish cold-start offline support.
5. Record timestamp, entry, memo ID, attachment counts, feedback, result and evidence path. Results may pass, fail or be externally blocked; page readability is not successful clipping.
6. Delete this run's memos/resources/tokens; compare initial ID sets to preserve existing data. Clean only this run's objects.
