# 可再次查看的分享密码

笔记和笔记本分享密码复用现有 AES-GCM Secret 加密组件。数据库保留 PBKDF2 哈希用于验证访客输入，同时保存密文，供登录后的单个分享管理接口读取密码。公开接口、分享列表和审计记录不返回密码。Web 客户端展示服务端响应，不再把新密码保存在 localStorage 或 sessionStorage 中。

优先使用 `EDGE_EVER_CREDENTIALS_ENCRYPTION_KEY` 作为根密钥，未配置独立根密钥时使用 `EDGE_EVER_AUTH_PASSWORD` 或 `EDGE_EVER_AUTH_PASSWORD_HASH`。分享加密使用独立的用途前缀，并与分享 token 绑定。本地开发已提供凭据密钥；Docker 将其持久化到 `/data/edgeever-secrets.json`。Docker 和 Cloudflare 共用此业务逻辑。

请在数据库之外单独备份根密钥。轮换时，把旧独立根密钥保留在 `EDGE_EVER_CREDENTIALS_ENCRYPTION_KEY_PREVIOUS`，或把旧认证根密钥保留在 `EDGE_EVER_AUTH_PASSWORD_FALLBACK`。所有匹配密钥丢失后，密码无法显示，但访客仍可通过哈希验证原密码。重新生成会使用当前根密钥保存新密文，并立即使旧密码和解锁 Cookie 失效。缺少根密钥时，会在修改密码前阻止生成，不会退回明文存储。

Migration `0069` 新增可空的密文列，不改写已有哈希或链接。只有哈希的旧密码仍可使用，但无法从服务端恢复；重新生成一次后即可跨设备查看。旧客户端的浏览器缓存不再作为显示密码的来源。表单提交密码不在此次变更范围内。

部署新服务端前先应用 Migration。回滚应用代码时保留新增列，仍可使用原有哈希验证。如果旧服务端修改了密码，再次升级后应重新生成，以更新密文。不要通过删除哈希或恢复旧数据库快照回滚。

自动验证会原地升级已有的纯哈希笔记本分享，检查原密码和解锁 Cookie，再重新生成并通过新的登录请求读取密码。路由测试覆盖密文存储、清除、密钥轮换或丢失、工作空间隔离、API Token 或匿名请求拒绝，以及分享列表不含密码。这些检查不代表已完成生产部署或原生设备验收。
